# Game Design Archive

![Status|136](https://img.shields.io/badge/status-Keeping%20Update-orange)

个人游戏设计学习与思考记录。

主要记录游玩过程中产生的问题、分析以及设计思考，
包含玩法、系统、叙事、角色等方向。

相比单纯评价游戏，更关注：

> 为什么这样设计，以及它如何影响玩家体验。
